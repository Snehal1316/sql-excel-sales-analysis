# Sales Data Analysis using MySQL and Excel

## Overview

This portfolio project analyzes 240 synthetic retail technology order lines from January–December 2025 using MySQL and Microsoft Excel.

The dataset is synthetic practice data and does not represent actual company performance.

## Project Objective

The objective of this project is to analyze sales and profitability and identify trends across:

- Months
- Regions
- Product categories
- Sales channels

The project demonstrates a complete beginner-level data analysis workflow from data validation and SQL analysis to Excel dashboard development.

## Tools Used

- MySQL Community Server
- MySQL Workbench
- Microsoft Excel
- GitHub

## Project Files

- `sales_data.csv` — source dataset containing 240 synthetic order lines
- `sales_analysis.sql` — MySQL schema, validation queries, analysis queries, and business questions
- `Sales_Analysis_Dashboard.xlsx` — Excel workbook containing the dashboard, source data, summary data, PivotTables, slicers, and documentation
- `dashboard.png` — preview of the completed Excel dashboard

## Dataset

- **Records:** 240 order lines
- **Period:** January–December 2025
- **Industry:** Retail Technology
- **Data type:** Synthetic practice data

## Project Workflow

1. Imported the sales dataset into MySQL.
2. Performed data-quality validation checks.
3. Calculated overall sales, profit, order lines, and profit margin.
4. Analyzed monthly sales and profit trends.
5. Analyzed regional sales and profitability.
6. Analyzed product category performance.
7. Analyzed sales channel performance.
8. Validated SQL results against Excel dashboard totals.
9. Built an Excel dashboard with KPI cards and charts.
10. Created PivotTables for Region, Product Category, and Sales Channel.
11. Added interactive slicers for Region, Category, and Channel.
12. Verified that the PivotTables update correctly when slicers are used.

## Key Business Insights

- South generated the highest regional sales at approximately ₹18.99 lakh.
- Computers generated the highest sales among product categories at approximately ₹52.84 lakh.
- Accessories generated the highest profit margin among the product categories.
- Online was the highest-performing sales channel by sales.
- Monthly sales and profit varied significantly across 2025.
